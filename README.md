# Subscriber — Event-Driven Architecture (Module 9)

**Nama**: Galih Nur Rizqy  
**NPM**: 2406343224

## Deskripsi

Program ini adalah **subscriber** dalam sistem Event-Driven Architecture. Subscriber bertugas mendengarkan (listen) event yang dikirim ke message broker RabbitMQ, lalu mengkonsumsi dan memproses setiap event yang masuk. Event yang didengarkan adalah `user_created` yang berisi informasi `user_id` dan `user_name`.
